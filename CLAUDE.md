# veschi

Документация для разработки — в `docs/`: `spec.md` (что делает приложение), `architecture.md` (как устроен код), `decisions.md` (принятые решения, в том числе пожелания Noah по интерфейсу). Перед изменением интерфейса загляните в `decisions.md`.

## Соглашения интерфейса

- Интерфейс на русском.
- **Обязательные поля — только красная звёздочка** (`RequiredMark` после подписи), без слов «обязательный» / «обязателен» / «необязательно» в подписи или подсказке. Если требование идёт из категории, под полем остаётся подсказка, откуда оно: «Из категории «Еда»» (`fromCategories`). Подробнее — `docs/decisions.md`, «Обязательные поля».
